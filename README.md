# 사주 코드 (Saju Code)

태어난 순간의 하늘을 계산해 사주팔자를 풀어 주는 웹앱입니다. 서버 없이 `index.html` 한 파일로 동작합니다.

- 양력·음력(윤달 포함) 입력: 한국 표준시 기준 삭·중기 천문 계산으로 변환
- 사주 네 기둥, 오행, 관계 코드(십성), 신살, 대운
- 2026·2027·2028년 운세: 분야별 점수, 충·합·삼재·귀인 신호, 월별 흐름
- 띠, 서양 별자리, 수비학 생명수, 관상 셀프 체크(Self Check)

배포: GitHub Pages (`main` 브랜치 루트) + 사용자 도메인 `www.saju-vottary.com` (`CNAME` 파일)

> 전통 해석 틀을 옮긴 엔터테인먼트용 분석이며, 입력 정보는 브라우저에만 저장됩니다.

## AI 인생설계 (`/life`)

`life/index.html` — 사주명리·성향 탐색 설문·서양 점성술·관상 셀프 체크를 계산 엔진으로 분석하고, 공통 테마와 모듈 간 차이를 하나의 통합 보고서로 정리하는 MVP입니다. 주소: `https://www.saju-vottary.com/life/`

- 계산과 해석 분리: 사주(만세력)·점성술(저정밀 궤도 계산, 홀사인 하우스)·설문 점수는 코드로 계산
- 이 정적 사이트에서는 규칙 기반 통합 보고서만 동작합니다 (AI 보고서는 Claude 아티팩트 환경에서만 사용 가능)
- 입력은 브라우저에만 저장되며, "내 데이터 삭제"로 지울 수 있습니다
